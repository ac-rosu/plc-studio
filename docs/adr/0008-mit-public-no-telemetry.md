# MIT license, public repository, no telemetry

The extension is free, MIT licensed, developed in a public GitHub repository and published on the VS Code Marketplace. It collects no telemetry and makes no network calls, which keeps industrial users' IT departments comfortable. The public corpus therefore contains only blocks written for this project; real project blocks stay in a gitignored private corpus.

## Considered Options

- Free but closed source, to keep a paid tier possible: rejected by the owner in favour of MIT.
